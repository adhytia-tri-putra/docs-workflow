# Git Workflow Docs

Project dokumentasi statis sederhana mengenai alur kerja Git untuk kolaborasi tim.

## Menjalankan project

Tidak ada dependency yang perlu dipasang. Buka `index.html` langsung di browser, atau jalankan local server:

```bash
npx serve .
```

Lalu buka alamat yang ditampilkan di terminal.

## Isi dokumentasi

- Persiapan dan konfigurasi Git
- Strategi penamaan branch
- Alur kerja harian
- Conventional commit sederhana
- Checklist pull request
- Penyelesaian merge conflict
- Git cheat sheet
